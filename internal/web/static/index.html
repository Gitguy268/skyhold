Skyhold

Stage files, back them up to any cloud, then drop the local copies.

No access token. Open the full URL that skyhold serve printed.

Set up

The release password is asked every time Skyhold deletes local files. It cannot be recovered, so pick one you will remember.

Your cloud key

Write this down and keep it away from this computer. With it and the remote you can recover your files on any machine. Without it nobody can decrypt the cloud copies, you included.

Clouds

Anything rclone accepts: a remote from rclone.conf like b2:bucket/backup, or a connection string like :sftp,host=nas.local,user=me:backups. Stored in the OS keychain.

1 · Pick files

Picked files are copied into the encrypted vault. Folders are added with everything inside.

2 · Vault

Upload sends each file to every cloud. Verify checks the cloud copies byte for byte.

3 · Release

Checks every file in the cloud again, then destroys the vault key and deletes the vault and the original files. An original that changed since you added it is kept.

Released

Files that now live only in the cloud. Restore downloads them and checks each one.
